# YidStore Connector

This add-on lets the **Apps** tab in YidStore install apps on Home Assistant OS.

You don't need to install it yourself. In YidStore, open **Apps** and click **Install add-on**. YidStore installs and starts it, and keeps it up to date.

There is nothing to configure.

## Option

- `poll_seconds`: how often (in seconds) the add-on checks YidStore for work. The default is 15.
